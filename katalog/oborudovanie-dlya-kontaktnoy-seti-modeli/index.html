    Оборудование для монтажа контактной сети

    Техника для монтажа контактной сети железных дорог: шпилевые установки и установки постоянного натяжения, натяжные стойки барабанов, стойки для смотки контактного провода, дорожно-железнодорожные установки, ролики и измерительные приспособления. Подбор по усилию и числу проводов.
